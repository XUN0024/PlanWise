# 附件预览

实现日期：2026-11-06（Asia/Kuala_Lumpur）。无需新增 SQL、Storage 配置或环境变量。

## 使用方式

- 已上传完成的附件在 Delete 左侧提供 Preview；上传未完成时禁用。
- 弹窗预览 PDF、PNG、JPEG、WebP。其他类型显示下载入口，不执行附件中的 HTML/SVG。
- PDF 支持滚动、页码跳转、缩放、适合宽度；图片支持缩放和适应窗口。
- 右上角提供下载原文件、打印、占位的更多图标及关闭按钮。
- 加密 PDF 显示说明，建议下载后使用阅读器打开；损坏文件和网络失败支持提示/重试。

## 实现

- 沿用当前账号的鉴权 Storage 下载，预览请求可取消；bucket 仍是私有。
- 缓存当前弹窗的 Blob，下载原文件不重复请求。关闭或切换账号时取消请求、
  销毁 PDF 任务、撤销图片 URL，关闭后恢复焦点；正文草稿保持在原有编辑器中。
- 使用 PDF.js compatibility build，兼容 Electron 37 缺少 Uint8Array.toHex 的环境。
  PDF.js、worker、CMap、字体和 WASM 资源打包到本地，不使用第三方在线预览服务。
- Renderer 使用 Webpack web target，支持浏览器和 Electron；原生桌面保存/打印
  通过 attachment-preload.js 和受限 IPC 完成，主进程校验发送窗口和主 frame。
  修改 preload/main 后需完整重启 Electron；浏览器刷新即可。
- 打印逐页生成独立的栅格打印文档，包含全部页面；不打印笔记页面。混合页面尺寸
  统一适配首张纸张，保持各页内容完整。下载始终保存原始文件，不重新生成 PDF。
- 为限制打印准备的内存，最多 1000 页、128MiB 图片数据，单页最多 800 万像素。
  超限提示下载后使用阅读器打印。PDF 打印是栅格输出，不保留可选中文本/矢量结构。
- 桌面下载使用系统保存对话框；浏览器沿用下载设置。打印交给系统/浏览器对话框，
  不静默发送到打印机。桌面打印临时文件在完成、取消、失败后清理。
- 更多按钮为禁用图标；第一版不含批注、全文检索、Office 转换或 PDF 密码输入。

## 验证

- `npm test`：组件状态、文件类型、私有下载凭证与 AbortSignal、Blob 清理、
  打印全部页、IPC 来源校验、上传流程等回归。
- `npm run test:preview`：使用本地生成的两页 PDF，在隐藏 Electron 窗口和 Chrome
  headless 中运行真实预览。Electron 输出 PDF 并重新解析页数，检查两页仍为两页；
  检查关闭弹窗后正文草稿保留。测试不访问线上 Supabase。
- 测试产物在忽略的 `.preview-smoke/` 目录，包括桌面/浏览器截图及打印 PDF。
  集成测试脚本默认使用当前 Windows 的 Chrome 安装路径，其他机器需调整路径。
- 仍需人工在线验收：真实私有附件、大文件/长文档、中文字体 PDF、加密/损坏文件、
  图片、系统打印对话框、保存文件名与打印机输出；测试不会自动操作真实打印机。

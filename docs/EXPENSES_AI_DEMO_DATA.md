# Expenses 历史模拟数据与 AI 核对基准

更新：2026-11-07，Asia/Kuala_Lumpur。批次：`PWDEMO-20261107-V1`。

本文件由 `node scripts/generate-expense-demo.cjs` 生成；不会连接数据库。金额按整数分计算，再由现有 PostgreSQL 统计 RPC 独立核对。

**本轮仅准备模拟支出与预期结果；PW AI 的任务/支出业务查询仍需另外接入后端。导入数据不会自动赋予模型读库能力。**

## 数据范围

- 256 笔，2026-05-01 至 2026-11-06，MYR，合计 **RM 14480.64**，平均每笔 RM 56.57。
- 覆盖七种分类、六种支付方式及未记录；每个完整月份超过 25 笔，便于发现只统计当前页的错误。
- 描述统一带 `[PWDEMO-20261107-V1]`。最大单笔：2026-10-18，购物 · 学习用笔记本电脑，RM 2499.00。
- 2026-08-30 与 2026-11-07 没有模拟支出；两组跨月 23:59/00:00 边界；RM 0.10 + 0.20 + 0.29 精度样本；两笔看起来相同但应分别计数的午餐。
- 所有 created_at 故意设为 2026-11-07 模拟补录时间；updated_at 由原有触发器生成。消费统计必须使用 expense_date，不能按录入日期汇总。
- 11 月只包含 1–6 日，不能与整个 10 月直接比较并宣称节省；应比较相同日期范围或说明未完月。

## 导入步骤

1. 在目标 Supabase 项目的 Authentication → Users 复制目标账号 **User UID**。使用空测试账号最容易逐项核对；导入当前账号也可以，但整体总额会混入原有真实账单。
2. 在 SQL Editor 打开并粘贴 [seed SQL](../database/seeds/20261107_expenses_demo_seed.sql)，将配置行 `target_uid text := 'PASTE_USER_UID_HERE'` 改为真实 UID（保留引号），再运行整个文件。不要修改占位符检查逻辑。
3. 首次 expected_batch_rows 应为 256，newly_inserted 为 256；未编辑模拟记录时重跑 newly_inserted 为 0，不重复、不覆盖已有记录。
4. 打开 [verify SQL](../database/seeds/20261107_expenses_demo_verify.sql)，同样只填写配置行的 UID，再运行；missing_rows、edited_rows 应为 0，19 个问题的 passed 应全部为 true。验证会使用 authenticated 身份及现有统计 RPC，结束后 ROLLBACK 清理临时状态。
5. 刷新 Expenses，搜索 `PWDEMO-20261107-V1` 只看本批模拟记录；查看统计、月趋势、分类、支付方式和分页。已有支出不会被删除。

这不是 schema migration，不要放进自动生产迁移。前提是已经运行现有 Expenses CRUD、payment/time、statistics 三份迁移；本轮不修改权限策略或添加服务端 Secrets。若 SQL 报错使事务中止，先执行 `ROLLBACK;`，检查 UID/已有迁移后重跑完整文件。

## 模型解释怎样验收

- 数字由数据库返回；模型负责表达与说明，不凭最近 25 条列表心算，也不拿聊天记忆代替查询。总额、笔数、均值、分组、日期边界必须与 verify/JSON 对齐。
- 用户问“为什么 10 月上涨”：可引用已记录的学习用电脑及其金额，不能编造购物动机或把相关性写成确定原因。
- 用户问“我超预算了吗”：当前没有预算数据，应说明无法判断并询问预算；不能把某个月的支出当作用户预算。
- 本月是部分月份，比较需说明截止日期；月份和时刻按马来西亚本地日历，不能误用 created_at 或 UTC 平移消费日期。
- 模拟数据本身不检验跨账号隔离；业务查询接入后仍需用第二个账号验证 API 不能读取本账号记录。

## 清理（可选）

只在不再需要本批数据时运行 [cleanup SQL](../database/seeds/20261107_expenses_demo_cleanup.sql)，同样只填写配置行 UID。按批次确定的 ID + 目标用户 + 描述标记删除，不按整个日期范围删除。若模拟记录后来附加了收据，脚本会拒绝删除，先在应用内清理收据，避免留下 Storage 文件。移除了描述标记的模拟记录会保留并报告 remaining_deterministic_rows，需要人工核对。
